## 正式素材准入

品牌负责人需提供已批准的矢量素材：

- `company-logo-horizontal.svg`：横版，导航或登录页；
- `company-logo-square.svg`：方形，favicon/紧凑侧栏；
- `company-logo-on-dark.svg`：深色背景；
- `company-logo-on-light.svg`：浅色背景。

每个 SVG 必须含 `viewBox`，不得含 `<script>`、事件属性、外部 URL 或 base64 内嵌位图。未经批准不从截图描摹、不用生成式工具臆造公司 Logo。素材未提供时，本阶段为 `BLOCKED`，不得把临时图标认定为品牌验收通过。

## 当前替换点基线（2026-08-10 扫描）

- `front/index.html` 当前 favicon 指向外部 URL，必须改为本地批准素材；
- `front/src/pages/Login.tsx` 包含系统名称、登录区和版权区，是横版/方形 Logo 的主要挂载点；
- `front/src/layouts/AppShell/index.tsx` 是桌面侧栏、移动抽屉和页头品牌入口；
- `front/src/i18n/zhCN.ts` 是系统名称的集中语言资源；
- `front/src/api/http.ts` 注释仍含脚手架部署路径文字，品牌清理时一并核对，但不得改变真实接口路径。

## 自动扫描与构建

```bash
rg -n 'Scaffold|scaffold' front/src front/index.html
rg -n 'https?://.*favicon|static-card\.dushu365\.com' front/src front/index.html
cd front
npm test
npm run type-check
npm run lint
npm run build:prod
```

前两条命令在完成品牌替换后应无活动品牌残留；代码注释命中也必须人工判定是否需要清理。素材负责人、业务负责人和前端验收人共同签署后才可通过。
